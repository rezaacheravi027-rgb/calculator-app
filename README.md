# ماشین حساب پیشرفته

یک ماشین حساب مدرن و قدرتمند با رابط کاربری تاریک و زیبا.

## ویژگی‌ها

- عملیات پایه (جمع، تفریق، ضرب، تقسیم)
- عملیات پیشرفته (جذر، توان، درصد)
- حافظه (Memory: M+, M-, MR, MC)
- تاریخچه محاسبات
- پشتیبانی کیبورد
- طراحی Responsive

## نصب و اجرا

فقط فایل `index.html` رو در مرورگر باز کنید.

## تکنولوژی‌ها

- HTML5
- CSS3
- Vanilla JavaScript
